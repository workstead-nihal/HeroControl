# Hero Control

Mobile-first static website inspired by https://herocontrol.in. Built with semantic HTML, responsive CSS and vanilla JavaScript. No build step or dependencies.

## Preview
Serve this directory with any static HTTP server, for example `python -m http.server 8080`, then open http://localhost:8080.

## Features
- Responsive navigation with Escape-key support
- Filterable product catalogue with accessible state announcements
- Product-specific email enquiries, phone and WhatsApp links
- Manual and drawing requests via email
- Reduced-motion support and visible keyboard focus

Contact details and product images are sourced from the existing Hero Control website. Confirm image rights and product details before public launch. Resource links request documents from the team; no downloadable manuals were supplied.

## Hosting
Publish the repository root with GitHub Pages (Settings → Pages → Deploy from a branch → main → / root), or use any static hosting provider. No credentials or backend are required. Email links use the visitor's mail application.

## Pages
- `index.html` — Home, with product previews and company introduction
- `about.html` — About us, our approach and applications
- `products.html` — Product catalogue with category filters
- `downloads.html` — Downloadable enquiry checklist and technical document requests
- `contact.html` — Contact channels, email composer and common questions

The contact form prepares an email in the visitor's mail application; the visitor must send it. No form data is stored by the website. Manufacturer documents are request-only until verified files are supplied.
